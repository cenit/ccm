# 2.0.0

`utils.psm1` becomes the `CCM` PowerShell module (`CCM.psd1` + `Public/` +
`Private/`). Every function is now verb-noun; the old names (`activateVenv`,
`MyThrow`, `DownloadNinja`, ...) remain as exported aliases and `utils.psm1` is a
shim that imports the module, so existing scripts keep working. Breaking: module
functions run with `$ErrorActionPreference = 'Stop'`.

Also new: `Initialize-CcmLogging`/`Stop-CcmLogging` replace per-script
transcripts, `ci-checks.ps1` quality gates, Azure DevOps pipeline templates for
C++, AWS ECS and skill repositories, the AWS ECS deploy/preview/teardown scripts,
`build-tc.py` (replaces `build-tc.ps1`), more Find modules, and a Pester suite
run by GitHub Actions.
